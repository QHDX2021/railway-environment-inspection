① 嵌入式开发工程师 紧急 本科及以上
25,000 × 14 薪

岗位职责：

  • Jetson Orin NX 16GB 主控板底层驱动开发（IMU / RTK / LiDAR / 相机）
  • 自研 PCB 一体化板调试（电源滤波 / PPS-PTP 同步 / 相机触发）
  • ROS2 Humble 节点开发与 ROS Bag 录制
  • SLAM 算法（FAST-LIO2 LiDAR-IMU 紧耦合）集成与优化
  • 设备联调（车顶 → 机箱 → 软件数据流全链路打通）

任职要求：

  • 5 年以上嵌入式 Linux 开发经验
  • 了解 C/C++ / ROS2 / Ubuntu 22.04
  • 熟悉 NVIDIA Jetson 平台（Orin NX 优先）
  • 熟悉 I2C / SPI / UART / 千兆网 / PPS 硬件接口
  • 有 IMU / RTK / LiDAR 传感器集成经验者优先

优先条件：武汉大学测绘 / 遥感专业；有车载 / 机器人 / SLAM 项目经验
