## 五、AI 异常识别系统（上位机核心模块）

### 5.1 模块定位

PC 端上位机新增 AI 异常识别能力，覆盖 **3 类铁路周边环境异常**，从 Month 2 起贯穿 11 个月（M2→M12），是项目核心交付之一。

### 5.2 核心指标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 多任务类别 | **3 类** | 异物入侵 / 周边环境变化 / 施工作业 |
| 推理硬件 | Orin NX 100 TOPS | 1024 核 Ampere + TensorRT FP16 |
| 训练数据 | 5000 张精标 | 预训练 + 现场微调 |
| 验收指标 | **mAP@0.5 ≥ 0.75** | 行业经验值 |
| 实时告警 | &lt; 500ms | Qt 上位机弹窗 + 声光 + 日志 |
| 推理速度 | &lt; 30ms / 帧 | TensorRT 优化后 |

### 5.3 AI 架构与数据流

```
[4 路相机 + LiDAR] → ROS2 话题
        ↓
[图像预处理] Orin NX 实时解码（640×640@30fps）
        ↓
[YOLOv8x 检测] TensorRT FP16 推理（<30ms / 帧）
        ↓
[多任务输出] 异物 / 周边变化 / 施工 类别 + 置信度
        ↓
[实时告警] Qt 上位机弹窗 + 声光 + 日志（延迟 <500ms）
        ↓
[数据回灌] 触发录像 + 标注工具 CVAT 闭环
```

### 5.4 多任务定义

| # | 类别 | 典型目标 | 判定标准 | 告警等级 |
|---|------|----------|----------|----------|
| 1 | **异物入侵** | 落石 / 行人 / 车辆 / 牲畜 / 抛洒物 | 距轨道中心 ≤10m | 🔴 紧急 |
| 2 | **周边环境变化** | 新建筑 / 违建 / 取土 / 植被生长 / 水浸 | 前后帧对比差异 ≥30% | 🟡 关注 |
| 3 | **施工作业** | 施工人员 / 机械 / 围挡 / 警示牌 | 保护区范围内人员/设备 | 🟡 关注 |

### 5.5 技术栈与工具链

| 环节 | 工具 / 框架 | 说明 |
|------|-------------|------|
| 检测框架 | YOLOv8x（ultralytics） | 多任务 + 高精度（mAP@0.5 ≥0.75 可达） |
| 备选框架 | Detectron2 | M2 评估后决定 |
| 推理加速 | TensorRT FP16 | Orin NX 部署（&lt;30ms / 帧） |
| 数据标注 | CVAT（自部署） | M4 起 1.5 万张精标 + 自标辅助 |
| 训练平台 | 云端 A100/A800 租赁 | M9-M11 月租 2,000 元 |
| 数据回灌 | Qt 客户端一键导出 | 触发录像自动入库 |
| 验证指标 | mAP@0.5 / 召回 / 误报率 | 每日训练日志归档 |

### 5.6 训练时间线（11 个月滚动迭代）

| 阶段 | 时间 | 数据量 | 里程碑 |
|------|------|--------|--------|
| **预研期** | M2-M3 | 公开数据集 | 框架选型 + 基础 demo |
| **预训练** | M4-M5 | 公开 1 万张 | CVAT 工具就绪 |
| **采集 1** | M6-M7 | 500 张现场 | 推理引擎集成 Orin NX |
| **微调 V1** | M8-M9 | 2000 张精标 | ★A7-AI V1.0（mAP ≥0.65） |
| **采集 2** | M10 | 3000 张 | ★A8-AI 数据扩展 |
| **微调 V2** | M11 | 5000 张 | ★A9-AI V2（mAP ≥0.75） |
| **验收** | M12 | 5000 张 | ★A10-AI 验收 + 实时告警 |

### 5.7 关键策略：预训练 + 现场微调

- **复用 YOLOv8x 公开权重**（COCO 80 类）→ 直接覆盖"车辆/行人"等基础类
- **铁路场景精标**仅需 5000 张即可达 mAP@0.5 ≥0.75（行业经验值）
- **现场数据闭环**：Qt 端一键导出 + 自动入库，触发录像快速积累
- **总投入 2.3 万**（GPU 租赁 8,000 + 标注外包 15,000），不算 Orin NX 已有算力
