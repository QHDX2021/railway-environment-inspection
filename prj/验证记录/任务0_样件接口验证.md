## 4. 关闭条件

- 样件实际型号与订单、BOM 一致；
- 每条物理链路有端口、供电和驱动证据；
- 带宽、写入、功耗和温度数据回填到验收矩阵；
- 未关闭项有责任人、下一步和风险，不得用“待确认”直接进入最终采购冻结；
- 任务 0 的结论同步回写 `05_硬件选型确认表.md`、`06_工控机截图参数核对.md` 和三端接口文档。
