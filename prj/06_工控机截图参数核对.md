# 工控机截图参数核对

日期：2026-09-30。来源为用户提供的四张商品截图，不是本次网页抓取成功，也不是独立的厂商规格核验。以下明确区分商品页标称、图片观察和待确认事项。

## 1. 可以识别的产品

商品介绍使用“Jetson Orin NX SUPER 套件”，采用 NVIDIA Jetson Orin NX 核心模组，展示载板、散热器和风扇。用户已选择 16GB、基础套餐。

对照图同时包含 8GB 普通、8GB SUPER、16GB 普通、16GB SUPER，截图没有显示已选 SKU 或基础套餐清单。因此以 Orin NX 系列 16GB、ARM64 作为当前设计依据，SUPER 档位和套装内容不能仅凭宣传标题锁定。

## 2. 16GB 参数摘录（商品截图标称）

| 参数 | Orin NX 16GB 普通 | Orin NX 16GB SUPER |
|---|---|---|
| GPU | Ampere，1024 CUDA 核心、32 Tensor 核心 | 同左 |
| CPU | 8 核 Arm Cortex-A78AE，64 位 | 同左 |
| CPU 最大频率 | 2.0GHz | 2.0GHz |
| 内存 | 16GB、128-bit LPDDR5 | 同左 |
| 内存带宽 | 102.4GB/s | 102.4GB/s |
| GPU 最大频率 | 918MHz | 1173MHz |
| AI 算力 | 100 TOPS（稀疏），50 TOPS（密集） | 157 TOPS（稀疏），78 TOPS（密集） |
| 功率档位 | 10/15/25W | 10/15/25/40W |
| 深度学习加速器 | 2×NVDLA v2 | 同左 |
| 外部存储 | 支持外部 NVMe | 同左 |

这些是商品页的配置/能力标称。40W 位于模组功率对照项，不能作为整机包含雷达、相机、硬盘、4G 和电源损耗后的总功耗。AI TOPS 不能换算成采集带宽或 Windows 后处理速度。

## 3. 接口与配套：分别记录证据层次

### 参数表和宣传图所写

- “USB（核心板）”：3 个 USB 3.2 Gen 2（10Gbps）、3 个 USB 2.0。
- 2 路 CSI，22pin、0.5mm 间距。
- DP 显示、Type-C 数据接口。
- `M.2 Key E + M.2 Key M*2`。
- 支持 PoE 供电、赠送 M.2 网卡、提供系统镜像及 ROS/AI 视觉开发资料。

上述接口表带有核心板能力和商品配套描述，不能直接当作已安装载板的全部可用接口。PoE 描述未说明是设备受电还是对外供电，不能据此断言可直接给工业相机供电。赠送网卡的有线/无线类型、速率和插槽占用也未明确。

### 产品外观图可见

- 正面可见 1 个 RJ45 网口。
- 可见两组蓝色双层 USB-A 插座及一组白色双层 USB-A 插座，共 6 个外露 USB-A 口。
- 可见 Type-C、圆形电源插座、排针及板上连接器。
- 模组上有较大的散热器和风扇。

不能由照片确认每个 USB 口的速率、内部共享带宽、电源能力，或判断板背面是否还有接口。照片的插座分组与表中“核心板 3＋3”口径不同，需载板手册澄清。单个可见 RJ45 也不能证明整套只有一个网口。

## 4. 对本项目的直接影响

1. **软件架构**：Linux 以 ARM64 为目标；海康相机和其他驱动需核对 ARM64 Linux 支持。商品提供 ROS 资料不代表必须使用 ROS。
2. **网络资源**：取消“已经有双网口、无需扩展”的既定假设。XT32、Surface 局域网和可能的 GigE 相机要统一做拓扑与带宽核算；是否需交换机或网卡由实际载板决定。
3. **存储连接**：保留三星 2×1TB SSD＋希捷 2×8TB HDD 的需求。即使双 M.2 Key M 可用，也需核查规格和资源占用；HDD 的数据转接与独立供电路径仍未落实。
4. **相机接口**：板上 CSI 不等于海康工业相机接口。先确定相机具体型号及 GigE/USB，再分配端口、触发线和供电。
5. **散热**：图片套件使用风扇，和原整机“纯被动散热”方向存在差异。不能未经热测试直接拆除套件风扇；是否保留箱内风扇或改导热结构，需要整机设计决定。
6. **电源**：电源输入电压、接头极性和峰值电流未显示。24V 电池能否直供该载板不能假定，需核对输入范围及 DC-DC。
7. **职责边界**：Linux 继续仅负责采集、存储、配置和 RTCM；不会因截图宣传 157 TOPS 而新增在线 AI 或解算任务。

## 5. 尚缺的商品信息

- 所选 16GB 基础套餐对应普通还是 SUPER，以及配套系统/功率模式。
- 商家品牌、套件完整型号、载板型号和版本。
- 基础套餐是否包含 SSD、电源适配器、风扇、M.2 网卡和天线。
- 网口数量/速率、网卡类型、USB 拓扑、M.2 插槽规格与互斥资源。
- 输入电压、散热要求、温度范围及机械尺寸。

以上信息用于具体接口设计，不影响三端职责已经确定的结论。
