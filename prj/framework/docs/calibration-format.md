# 标定、轨迹和点云

标定文件保存版本、设备集合版本、适用设备 ID、坐标系、相机内参、雷达/相机到 IMU 的外参、双天线基线、杆臂和时间偏差。`calibrate` 先校验这些引用，再写入独立文件；原始任务不会被覆盖。

`solve_trajectory` 当前是可替换的合成基线：它验证时间标签质量、时钟域和 `boot_id` 连续性，并将输入样本转换为带时间标签的位姿序列。真实 GNSS/IMU 融合算法应在相同的 `TrajectoryResult` 中记录输入任务和标定版本。

`build_point_cloud` 以位姿索引进行刚体变换，保留输入任务与标定版本。真实系统接入时间插值、运动补偿、雷达外参和坐标系转换时，仍需保持结果独立写入和输入引用可追溯。
