# 三端公共协议

## 传输帧

`frame.cpp` 使用固定小端字段编码，帧头为 `RI`，版本为 `1`。布局为：

| 字段 | 长度 |
|---|---:|
| 魔数 `RI` | 2 |
| 版本 | 1 |
| 保留 | 1 |
| 类型 | 2 |
| 序号 | 4 |
| 负载长度 | 2 |
| 负载 | N（最大 4096） |
| CRC32 | 4 |

帧解码器支持分段输入、粘包和坏 CRC 统计。结构体内存不会直接作为线上格式。

## 消息负载

消息负载由 `messages.hpp` 定义，布局为 `type:u16`、`request_id:u32`、`payload_size:u16`、`payload`，均为小端编码，负载最大 4096 字节。消息可被放入传输帧中，`request_id` 用于关联请求和响应。

已分配类型包括能力、状态、参数读写、任务启停、IMU、PPS 映射、触发、电源、关机和错误。未知类型由上层按错误消息处理，不能静默当作成功。

## 时间标签

每个 `TimeTag` 携带 `ClockDomain`、`boot_id`、计数频率和 `TimeQuality`。只有时钟域、启动编号和计数频率一致时，`compare_time` 才允许比较；否则结果为 `Incomparable`。
