# AI 与跨次变化数据契约

`DatasetManifest` 固定场景、路线、采集时间、天气、标签版本、数据划分、脱敏状态和任务列表。清单文件和模型版本必须随结果保存，不能只在界面上显示。

`run_ai` 的输入引用任务、原始文件、输出目录和模型版本；模型未安装时返回 `NotSupported`，不会生成空的成功结果。每个 `Detection` 预留类别、置信度、证据引用、时间标签、位置和模型版本。

`analyze_change` 要求两次任务引用、注册质量和配对点集。注册质量不足、点集不匹配或输入缺失时失败；通过后输出带两次任务 ID、配准质量、变化位置、变化指标和人工复核状态的 `ChangeCandidate`。候选默认为 `unreviewed`，由 Windows 人工复核流程推进状态。
