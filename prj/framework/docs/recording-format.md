# 任务记录格式

一个任务目录至少包含：

- `task.meta`：任务编号、设备集合版本、配置快照、标定引用、模拟标志和任务状态。
- `data.rrec`：连续记录文件。
- `complete`：数据文件刷写成功、元数据已更新后才创建的完成标记。

## 记录

每条记录使用 `RIRE` 魔数，后跟小端长度、记录体和 CRC32。记录体保存流类型、流编号、设备编号、`TimeTag`（含时钟域）、序号、主机单调时钟、模拟标志和负载。单条负载上限为 16 MiB。

原始记录只追加，不覆盖。任务目录已存在时 `TaskWriter::create` 返回冲突。写入失败或进程退出前未执行 `finish` 时不会生成 `complete`，任务保持未完成。

## 读取与回放

严格模式要求所有记录完整、CRC 正确且任务有完成标记；遇到截断、CRC 错误或未完成标记时失败。恢复模式返回已经校验通过的前缀并报告坏偏移，`complete=false` 表示仍需人工确认。

`PlaybackFilter` 可按流编号、时钟域和 `boot_id` 筛选。回放取消返回 `Cancelled`，不会将取消误报为正常 EOF。
