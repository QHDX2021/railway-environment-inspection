# 交付清单

## 当前软件基线

- `prj/framework`：C++17/CMake 三端核心框架。
- `prj/framework/docs`：协议、记录、固件、Linux、Windows、标定和 AI 数据契约。
- `prj/framework/tests`：20 个 CTest，当前 Debug 全部通过。
- `.superpowers/sdd/09_项目实施计划/progress.md`：任务执行台账和硬件门禁说明。
- `prj/验证记录`：台架、掉电、连续采集和实车验证模板。

## 硬件/部署交付前置项

- 自研 PCB：STM32H750 固件、ADIS16477-3 SPI/DRDY、PPS、触发、电源和掉电测试记录。
- Linux 工控机：Orin NX 载板与 16 GB/SUPER SKU、JetPack、XT32、海康相机、UMD982 双天线、合宙 Cat4、三星 SSD/希捷 HDD 的型号、驱动和接口证据。
- Windows：Surface 设备、安装包、参数页面、局域网下载、回放/标定/轨迹/点云/AI/变化分析数据集。
- 工程资料：BOM、端口拓扑、带宽/存储/功耗预算、版本矩阵、部署手册、操作手册、维护手册和备件表。

只有上述硬件、现场和算法证据齐全后，才能把“主机模拟通过”升级为“整机验收通过”。
