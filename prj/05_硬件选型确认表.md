## 3. 接入和软件设计要求

### 多星多频天线与 UMD982

记录两根天线的主从身份、馈线、基线方向、安装关系和杆臂。具体天线需核查实际频段、接头、供电与 UMD982 配套条件，不能只记录“多星多频”。

### 海康工业相机

相机适配器独立封装厂商接口；待型号和 SDK 支持平台确认后选择 GigE/USB 链路。接入要求包括四路采集、硬件触发、参数读回、帧号和丢帧诊断。不能仅凭品牌认定已有目标架构 SDK 或特定触发能力。

### 三星固态与希捷机械

核查实际硬盘接口数量、转接器、供电、空间和振动条件。依据写入实测配置缓冲、分段和下载限速。18TB 是原方案标称容量，实际可用录制容量另算。

### 合宙 Cat4

Linux 管网络和 NTRIP，PCB 管供电及必要复位。具体型号确定后再选择 USB 网络、串口或厂家支持的接入方式，核对驱动、控制命令及供电峰值。Cat4 是通信类别，不能代替完整型号。

Linux 将匹配的 RTCM 消息送给 UMD982；Windows 配置 APN、差分地址、账号和挂载点。凭据不进入普通日志及采集快照。

### Surface Windows 上位机

完整保留深度参数设置、局域网下载、回放、标定、轨迹解算、点云生成、AI 识别和跨次变化分析职责。

具体型号确定前，不假设 CPU 架构及 GPU 能力，不把 CUDA/TensorRT 设为必备依赖，不承诺处理耗时。C++ 算法与 Qt UI 分离，使用后台任务、进度、取消和分块读取，界面考虑触控。

需确定有线或 Wi-Fi 局域网连接，是否需要网卡/扩展坞，以及本地磁盘能否容纳单次任务。性能评估在目标 Surface 上进行，不能未经确认把后处理迁回 Linux。
