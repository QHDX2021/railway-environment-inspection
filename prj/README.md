## 项目定位

定位模块已由用户最终明确为 **UMD982，采用双天线方案**。三端框架按该型号及双天线定位/定向需求组织。

接手并研发一套车载式铁路周边环境巡检设备：同步采集激光点云、图像、惯性及定位数据，完成定位与建图、数据记录和回放，识别异物入侵、施工作业和周边环境变化，并在上位机展示位置、证据与告警。

主链路：传感器 → 同步与驱动 → 数据记录及空间配准 → 定位建图 / AI 分析 → 展示、告警与结果导出。

原规划周期为 2026-10-15 至 2027-10-14，团队为技术负责人、嵌入式、PC 端、测试共 4 人；2027 年 4 月样机、5 月装车联调、10 月验收。本次保留这些时间锚点，新增的工作分解属于执行建议，不代表已批准的排期变更。

- **补充工作**：为形成完整工程链路，本次识别出的研发任务或配套需求；尚未计入原预算的项目会单独指出。
- 当前目录未发现车载产品源码、PCB 设计工程或测试报告，不能据此判断实际研发完成度。
- 本次是内部资料梳理，未进行供应商询价、器件官方参数核验或政策核验。

## 优先解决的五件事

1. 确定巡检车速、目标尺寸与距离、昼夜天气范围、安装位置及车辆供电条件。
2. 确定相机、镜头、Jetson 载板和全部接口拓扑，先验证多传感器持续采集。
3. 打通时间戳、硬件触发和外参标定，形成可回放、可追溯的数据集。
4. 明确三类 AI 任务的标注定义与评价方法，尤其是跨次巡检的环境变化检测。
5. 重新核对采购数量、研发打样费及验收范围，形成可执行的成本和进度基线。
