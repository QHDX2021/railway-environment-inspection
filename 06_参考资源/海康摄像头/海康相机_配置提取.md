# 海康工业相机配置提取

来源：`MV-CS050-80UMUC_20251231.pdf`
资料对应产品：`MV-CS050-80UM/UC` 二代工业面阵相机
提取日期：2026-10-09

## 1. 型号和当前选型结论

资料同时覆盖两个订货变体：

| 订货型号 | 类型 | 当前状态 |
|---|---|---|
| MV-CS050-80UM | 黑白 | 具体项目型号待确认 |
| MV-CS050-80UC | 彩色 | 具体项目型号待确认 |

两种型号共用主要硬件平台和接口。项目目前可以把 `MV-CS050-80UM/UC` 作为候选型号族，不能在未确认黑白/彩色变体前把图像通道和算法输入冻结为单一型号。

## 2. 采集配置

| 项目 | 手册资料 | 对项目的影响 |
|---|---|---|
| 传感器 | CMOS，全局快门 | 满足运动场景的全局曝光需求，仍需实车验证振动和运动拖影 |
| 靶面 | 2/3 英寸 | 镜头和视场需按安装距离、铁路目标尺寸重新选型 |
| 分辨率 | 2448 × 2048，约 500 万像素 | 作为四路图像原始数据格式基线 |
| 像元 | 3.45 μm × 3.45 μm | 用于镜头、景深和低照度评估 |
| 最大帧率 | 80 fps@2448×2048，Mono 8 或 Bayer BG 8 | 这是单相机、特定像素格式的标称峰值，不等于四路系统可持续帧率 |
| 黑白变体 | Mono 8/10/10Packed/12/12Packed | `MV-CS050-80UM` 使用 |
| 彩色变体 | Bayer BG 8/10/10Packed/12/12Packed；另支持 YUV/RGB 输出 | `MV-CS050-80UC` 使用；输出格式会显著影响带宽 |
| 曝光 | 15 μs～10 s | 需要按车速、光照和补光确定固定/自动曝光策略 |
| 增益 | 0～12 dB | 保存到任务配置快照，不能只记录图像文件 |
| 触发 | 硬触发、软触发、自由运行 | 本项目优先验证 PCB 硬触发；自由运行仅用于调试或降级 |
| ROI/降采样 | 支持自定义 ROI，1×1/2×2/4×4 下采样 | 是解决四路带宽和存储压力的候选手段，但需要画质验收 |
| 镜像 | 支持水平和垂直镜像 | 记录安装方向和软件镜像配置 |

## 3. 接口和供电

| 项目 | 手册资料 | 项目设计要求 |
|---|---|---|
| 数据接口 | USB3.0，兼容 USB2.0 | Linux 侧必须按 USB3 设备识别和压测，降为 USB2 时应告警并禁止默认为合格 |
| 协议 | USB3 Vision、GenICam | 适配器按标准接口封装，保留 MVS 作为厂商调试工具选项 |
| 数字 I/O | 6-pin P7：1 路光耦隔离输入 Line0、1 路光耦隔离输出 Line1、1 路双向可配置非隔离 I/O Line2 | 需取得 P7 针脚定义和电气时序，确认硬触发接入哪个 Line、是否需要外部电源/电平转换 |
| 供电 | 9～24 V，支持 USB 供电 | 不能同时假设 USB 供电和外部 9～24 V 供电；整机线束需冻结唯一供电方案 |
| 典型功耗 | 1.6 W@5 VDC（USB3.0 供电条件） | 以实际四路启动峰值和外部供电配置做整机功耗预算 |
| 镜头 | C-Mount | 四路镜头焦距、视场、光圈、滤光和防护窗另行确定 |

## 4. 结构和环境

- 外形：29 mm × 29 mm × 30 mm；
- 重量：约 87 g；
- 防护等级：IP40（正确安装镜头和线缆的条件下）；
- 工作温度：-30 ℃～60 ℃；
- 存储温度：-30 ℃～80 ℃；
- 湿度：20%～95% RH，无冷凝；
- 支持四面安装，外壳有 M2/M3 安装孔位，最终以机械图和实物为准。

## 5. 四路带宽初算

以资料给出的满分辨率、80 fps、8 bit 单通道/拜耳数据估算：

```text
2448 × 2048 × 80 × 1 byte ≈ 401 MB/s ≈ 3.21 Gbit/s（单相机原始像素）
4 路 ≈ 1.60 GB/s ≈ 12.83 Gbit/s（未计 USB3 Vision、主机、缓存和存储开销）
```

这说明以下配置不能直接作为首版整机目标：

- 四路相机都以 2448×2048、80 fps、8 bit 连续无压缩采集；
- 四路相机共享一个普通 USB3 Hub；
- 仅依据 Orin NX 核心板“有 USB3 接口”就认为四路带宽足够。

项目必须在最终载板上验证 USB 控制器拓扑、每个端口的共享关系、供电能力和 DMA/内存带宽，并通过以下一种或多种方式形成可验收配置：降低帧率、降低 ROI、使用触发采集、选择合适像素格式、分配独立 USB3 主控或增加经过验证的扩展方案。

## 6. Linux 接入建议

1. 使用 USB3 Vision/GenICam 能力查询读取型号、序列号、分辨率、像素格式、帧率、触发模式、曝光和增益；
2. 采集记录保留相机序列号、帧号、主机接收时刻、触发状态和丢帧计数；
3. 硬触发链路由 PCB 产生，Linux 负责下发触发频率和保存配置，不把软件收到 USB 包的时刻当作曝光时刻；
4. 四路相机启动前进行端口、带宽、供电和存储预检查；任一相机协商到 USB2 或能力低于任务配置时，任务进入明确失败/降级状态；
5. MVS SDK 作为厂商工具或适配层依赖，公共 C++ 协议层不直接依赖 MVS；
6. Linux ARM64 SDK 和驱动必须在最终 Orin NX/JetPack 上实测，Windows MVS 资料不能替代 Linux 验证。

## 7. 当前待确认项

- 四台相机最终选择 `UM` 黑白还是 `UC` 彩色，或两者混用；
- 具体固件、序列号、USB 线缆长度和是否带外部电源线；
- P7 连接器完整针脚、电气电平、硬触发输入和输出时序；
- Orin NX 载板 USB3 主控拓扑、端口共享、供电和扩展方案；
- 四路目标帧率、ROI、像素格式、曝光和存储时长；
- 海康 Linux ARM64 MVS/USB3 Vision 运行库及 JetPack 兼容版本；
- 镜头焦距、视场、安装姿态、遮光/防护窗和夜间补光。
