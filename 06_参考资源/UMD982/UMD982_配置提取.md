# UMD982 配置提取

来源：`UMD982_User Manual_CH_P1.0.0(2)(1).pdf`
手册版本：`UC-00-M78 CH P1.0.0`，2024 年 2 月初始版本
提取日期：2026-10-09

## 1. 先给结论

这份资料是 **UMD982 模块硬件介绍与硬件设计手册**，可以确认供电、引脚、天线、PPS、状态输出、机械和 PCB 设计约束；它没有提供完整的串口命令字典、默认波特率、消息配置命令、双天线基线设置命令或 NTRIP 客户端配置方法。

因此，本文件把内容分成三类：

- **手册确认**：可以直接写入 PCB 原理图、接口表和 Linux 设备适配边界；
- **项目建议**：结合本项目三端边界提出接线和软件归属，但仍需样件验证；
- **待补资料**：需要 UMD982 协议/命令手册、配套配置工具或实物串口测试才能冻结。

## 2. 手册确认的产品能力

| 项目 | 手册内容 | 对本项目的含义 |
|---|---|---|
| 产品 | UMD982，单北斗高精度定位定向模块 | 不能按多 GNSS 模块宣传口径配置；当前资料明确的是北斗频点 |
| 芯片 | UCD9810 | 记录到硬件版本和设备能力中 |
| 北斗信号 | B1I、B2I、B3I、B1C、B2a、B2b | 作为接收能力基线，实际固件能力仍需读回 |
| 定位/定向 | 支持双天线定向，Dual-RTK 双 RTK 引擎 | 两个射频输入必须保留主/从天线身份和安装基线 |
| 数据格式 | NMEA-0183、Unicore | Linux 适配器至少要能区分两类输出 |
| 差分输入 | RTCM 3.x | Cat4/NTRIP 由 Linux 接入后转给 UMD982 |
| 数据更新率 | 定位测向 20 Hz；原始观测量 20 Hz | 不能只按低频 NMEA 位置设计记录带宽 |
| PPS | 1PPS 输出，脉宽和极性可调 | 接入 PCB 时间同步电路；具体极性/脉宽需配置和示波器确认 |
| 其他接口 | UART、EVENT、RTK_STAT、PVT_STAT、ERR_STAT、RESET_N | 可用于主机数据、事件标记、状态诊断和复位 |
| 预留接口 | I2C、SPI、CAN 暂不支持 | 不作为本项目的生产通信链路 |

手册给出的性能是厂家条件下的参考值，不直接转成项目验收指标：RTK 平面 0.8 cm+1 ppm、定向 0.1°/1 m 基线、PPS 20 ns RMS、20 Hz 更新率等均需按实际天线、基线、环境和固件版本复核。

## 3. 供电配置

| 项目 | 手册确认值 | PCB 设计要求 |
|---|---:|---|
| VCC 工作范围 | 3.0～3.6 V DC；典型 3.3 V | 使用稳定的 3.3 V 电源，不能把 5 V/12 V 直接接入模块 |
| VCC 最大纹波 | 50 mV | 在模块供电引脚附近测量，纳入电源完整性测试 |
| 工作电流 | 典型 180 mA，最大 300 mA，条件为 VCC=3.3 V | DC-DC 和 PCB 电源开关按最大电流及上电冲击留余量 |
| 功耗 | 手册列出典型 600 mW | 以实际样件电流和电压测量作为整机预算依据 |
| V_BCKP | 2.0～3.6 V；常温工作电流小于 60 μA | 若需要热启动，保留后备电源；不使用热启动时按手册接 VCC，不能悬空/接地 |
| 上电起始电平 | VCC、V_BCKP 均需低于 0.4 V | 电源时序测试必须记录初始电平 |
| 上电斜坡 | 单调，不能有平缓处 | 用示波器确认无异常平台、下冲和振铃 |
| 下冲/振铃 | 小于对应电源的 5% | 作为 PCB 电源验收项目 |
| 重启间隔 | 电源降至 0.4 V 以下后，再上电间隔大于 500 ms | PCB 复位/掉电状态机必须满足该时间 |

手册同时提示模块内部有电容，上电可能有冲击电流；PCB 需要实测启动电流和电压跌落，不能只按 180 mA 典型值选电源。

## 4. 引脚和项目接线建议

### 4.1 必接和优先接入引脚

| 引脚 | 名称 | 手册功能 | 项目建议 |
|---:|---|---|---|
| 2 | ANT1_IN | 主天线射频输入 | 接主天线，保留 50 Ω 射频走线和 ESD/浪涌防护 |
| 36 | ANT2_IN | 从天线射频输入 | 接从天线；在任务配置中记录主从和基线方向 |
| 17/18 | RXD1/TXD1 | 串口 1，LVTTL | 候选主数据口；最终由 Linux 端口拓扑和消息带宽测试确定 |
| 19/20 | RXD2/TXD2 | 串口 2，LVTTL | 候选 RTCM/辅助数据口；不与串口 1 的职责重复，待实物验证 |
| 27/28 | TXD3/RXD3 | 串口 3，LVTTL，可复用 CAN | 候选调试/扩展口；生产设计中按 UART 使用，CAN 暂不启用 |
| 23/24 | VCC | 3.3 V 主供电 | 同一受控 3.3 V 电源域，旁路和纹波按手册设计 |
| 5 | V_BCKP | RTC/相关寄存器后备供电 | 按是否需要热启动选择独立后备电源或按手册接 VCC |
| 30 | PPS | 秒脉冲输出，脉宽/极性可调 | 接 STM32H750 定时器捕获输入；保存 PPS 质量和秒号映射 |
| 32 | EVENT | 事件输入，频度/极性可调 | 可接 PCB 触发/外部事件；配置方式需协议资料确认 |
| 33 | RESET_N | 低有效复位，至少 5 ms | 由 PCB 受控，硬件复位脉冲不短于 5 ms |
| 14 | ERR_STAT | 高有效异常状态 | 接 PCB 或 Linux GPIO，记录模块自检异常 |
| 15 | PVT_STAT | 高有效可定位状态 | 作为定位可用诊断，不替代完整 PVT 消息 |
| 16 | RTK_STAT | 高有效 RTK 固定解状态 | 作为硬件状态辅助；最终 RTK 状态以协议输出为准 |
| 1/3/4/34/35/37/41/43/45 | GND | 地 | 按参考布局连接，保证射频和散热回流 |

### 4.2 不得随意连接的引脚

- 11、12、13、29、31、38、39、40、42、44、46、47、48：保留脚，按手册要求悬空；
- 25、26：BIF 内部功能脚，需要按手册加 10 kΩ 上拉，不能悬空、接地或接外设 IO；
- I2C、SPI、CAN：资料明确暂不支持，不作为生产数据链路；
- UMD982 的 LVTTL 串口不能直接接 RS-232 电平，Linux 侧需要 3.3 V 电平兼容的 UART/USB 转换器。

## 5. 射频和双天线配置

手册推荐外部天线馈电采用独立的 `ANT_BIAS` 电源轨，避免天线端 ESD、浪涌和过压进入模块 VCC。参考设计给出：

- L1/L2：推荐 0603、68 nH 射频电感；
- C1/C3：100 nF 与 100 pF 并联去耦；
- C2/C4：100 pF 隔直电容；
- D1/D4：支持 2000 MHz 以上的高频 ESD 器件；
- D2/D3：按馈电电压和天线耐压选择 TVS；
- 天线输入最佳增益范围：手册表格给出 18～36 dB，典型值 30 dB，需结合所选蘑菇头天线确认。

双天线必须在设备配置和任务元数据中保存：

1. 主天线/从天线身份；
2. 两天线型号、序列号和馈线编号；
3. 天线相位中心间距、基线方向和安装坐标；
4. UMD982 输出的定向质量、基线解状态和使用的固件版本。

本手册没有给出双天线基线设置命令，不能凭本文冻结基线参数写入方式。

## 6. Linux/PCB 集成配置建议

| 配置项 | 建议值/归属 | 状态 |
|---|---|---|
| UMD982 数据口 | Linux 独占管理一个 UART；读取 NMEA/Unicore，向同一设备写入 RTCM | 架构已确定，实际 UART 和波特率待协议资料确认 |
| RTCM 来源 | Linux Cat4 → NTRIP → UMD982 | 架构已确定，消息类型和龄期策略待联调 |
| PPS | UMD982 pin 30 → PCB STM32H750 捕获 | 接线方向已确定，电平/极性/脉宽待测 |
| 事件 | PCB/外部事件 → UMD982 EVENT 或由 PCB 自己记录 | 需要按时间戳要求决定，不能同时无定义地使用两套事件链路 |
| 复位 | PCB 控制 RESET_N，低电平至少 5 ms | 硬件策略已确定，需示波器验收 |
| 定位状态 | PVT_STAT/RTK_STAT/ERR_STAT 作为辅助 GPIO 诊断 | 需决定接 PCB 还是 Linux GPIO，并避免与协议状态重复计数 |
| 配置入口 | Windows → Linux 参数服务 → UMD982 | 需要 UMD982 命令表或厂商配置工具资料 |
| 时间记录 | 保存原始 GNSS 时间、PPS 计数、主机接收单调时刻、boot_id 和质量 | 项目记录格式已支持，设备字段待实际映射 |

## 7. 当前不能从本手册确定的配置

以下内容必须补充 UMD982 协议手册、配置工具说明或串口实测，不能从本 PDF 推断：

- 默认波特率、数据位、校验位和停止位；
- UART1/UART2/UART3 的默认输出内容和端口分工；
- NMEA/Unicore 消息名称、字段定义、输出周期和启停命令；
- RTCM 3.x 支持的具体消息类型和写入端口；
- 双天线基线长度、航向模式、天线方向和定向输出配置命令；
- PPS 的默认极性、默认脉宽、对齐方式和配置命令；
- EVENT 的触发语义、默认频率/极性和时间戳输出方式；
- 参数保存到非易失存储的命令、重启生效规则和恢复出厂方式；
- 固件升级方式、版本查询命令和异常恢复流程。

## 8. 需要补充的验证记录

样件到位后，按以下顺序验证并回填项目矩阵：

1. 3.3 V 上电、V_BCKP、纹波、冲击电流和 500 ms 重启间隔；
2. 两路天线馈电、主从识别、基线方向和射频防护；
3. 三路 UART 的电平、默认波特率、消息输出和并发带宽；
4. PPS 极性/脉宽、秒号映射、EVENT 时序和 RESET_N 脉宽；
5. RTCM 注入、差分龄期、RTK_STAT 与协议解状态一致性；
6. 断电、复位、失锁、重获和配置保存/恢复。
